# 🌊 제주해녀체험 (Jeju Haenyeo Experience)

제주 해안 도로를 배경으로 펼쳐지는 인터랙티브 웹 애니메이션 프로젝트입니다.

## ✨ 주요 특징
- **인터랙티브 웹 경험:** 제주 해안 풍경과 해녀 테마를 결합한 생동감 있는 화면 연출
- **반응형 인터페이스:** PC와 모바일 브라우저 환경에서 모두 부드럽게 작동

## 🛠 사용 기술 (Tech Stack)
- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
